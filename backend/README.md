# Goalsetter MERN app

This is the goalsetter app.

## Usage

Rename the .env-example to .env and add your MONGO_URI

<br/>

NODE_ENV = production
<br/>
PORT = 5000
<br/>
MONGO_URI = Your MONGO URI
<br/>
JWT_SECRET = Your JWT SECRET
<br/>

### Install dependencies

```
# Backend deps
npm install

# Frontend deps
cd frontend
npm install
```

### Run Server

```
npm run server
```
