# Goalsetter MERN app

This is the goalsetter app.

## Usage

Rename the .env-example to .env and add your MONGO_URI

NODE_ENV = production
PORT = 5000
MONGO_URI = Your MONGO URI
JWT_SECRET = Your JWT SECRET

### Install dependencies

```
# Backend deps
npm install

# Frontend deps
cd frontend
npm install
```

### Run Server

```
npm run server
```
